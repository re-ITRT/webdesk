# WebDesk — 通用 Web 应用桌面化管理平台

> 轻量级、高可控性的 Web 应用桌面化运行与管理平台。将 Web 应用以“原生桌面应用”的形态呈现，提供深度的生命周期钩子、后台驻留能力及高度自由的界面定制功能，通过系统桌面快捷方式一键直达 Web 服务。

## 核心特性

- **单引擎渲染（WebView2）**：per-app 独立环境与身份隔离（cookie/密钥/扩展），Chromium 内核。
- **应用级身份（AppIdentity）**：cookie/密钥/插件按应用隔离，平台统一管理。
- **生命周期钩子**：启动前 / 关闭后脚本钩子，支持阻塞式启动、超时与退出码监控。
- **工作项驱动生命周期**：平台随“第一个 app 启动/最后一个工作项结束”而启停；默认无托盘图标，仅当存在后台驻留应用时动态出现。
- **后台持久化驻留**：关闭窗口隐藏不销毁渲染器，后台网络保活。
- **界面高度定制**：按应用控制浏览器原生控件、CSS/JS 注入、扩展按需加载。
- **桌面快捷方式入口**：一键创建 `.lnk`，`WebDesk.exe --launch <appId>` 直达。
- **单例 + 进程调度**：唯一主进程，IPC 指令转发，极速启动响应。
- **Web 管理控制台**：管理界面即平台首个内置 Web 应用（吃自己的狗粮）。

## 技术栈（已定案）

| 层 | 选型 |
|---|---|
| 语言/运行时 | C# / **.NET 10 LTS** |
| 原生薄壳 | WinForms（窗口承载 + 动态托盘 + 通知）|
| 渲染引擎 | WebView2（唯一引擎，Evergreen 默认，Fixed Version 共享目录 opt-in）|
| 本地 HTTP | ASP.NET Core Minimal API（管理 API + 静态控制台，仅回环+token）|
| 管理界面 | 内置 Web 控制台（HTML/CSS/JS，作为首个默认 Web 应用）|
| 进程/生命周期 | 命名互斥体 + 命名管道 IPC + Job Object 进程树回收 + 工作项驱动生命周期 |
| 配置 | JSON（`%APPDATA%\WebDesk\config\`）|
